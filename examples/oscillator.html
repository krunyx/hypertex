요약

HyperTeX 2.0 파서와 HTML 변환기를 처음으로 끝까지 연결해 만든 예제 문서. 수식 번호와 상호참조, 정리 환경, 접힌 증명, 단계별 유도, 매개변수, 한글 수식이 한 문서에 들어 있다.

매개변수 (기본값)
  • ω = 1 (0.5–3, 간격 0.1)

1 해밀토니안

질량 mm, 진동수 ω\omega인 1차원 조화 진동자의 해밀토니안은

H=p22m+12mω2x2H = \frac{p^2}{2m} + \frac{1}{2} m\omega^2 x^2(1)

이다. 사다리 연산자를

aa=mω2ℏ(x+imωp)= \sqrt{\frac{m\omega}{2\hbar}}\left(x + \frac{i}{m\omega}p\right)(2)
a†a^\dagger=mω2ℏ(x−imωp)= \sqrt{\frac{m\omega}{2\hbar}}\left(x - \frac{i}{m\omega}p\right)(3)

로 정의하면 [a,a†]=1[a, a^\dagger] = 1이고, 식 (1)는 H=ℏω(a†a+12)H = \hbar\omega\left(a^\dagger a + \tfrac{1}{2}\right)로 쓸 수 있다.

2 고윳값

정리 1 (에너지 준위). HH의 고윳값은 En=ℏω(n+12)E_n = \hbar\omega\left(n + \tfrac{1}{2}\right), n=0,1,2,…n = 0, 1, 2, \ldots이다.

증명

N=a†aN = a^\dagger a라 하면 [N,a]=−a[N, a] = -a이므로 aa는 NN의 고윳값을 1 낮춘다. 노름이 음이 될 수 없으므로 바닥 상태 |0⟩\left| 0 \right\rangle에서 a|0⟩=0a\left| 0 \right\rangle = 0이고, 고윳값은 음이 아닌 정수다.

∎

바닥 상태 에너지의 유도:

  1. a|0⟩=0a\left| 0 \right\rangle = 0 (정리 1의 증명)

  2. H|0⟩=ℏω(a†a+12)|0⟩=12ℏω|0⟩H\left| 0 \right\rangle = \hbar\omega\left(a^\dagger a + \tfrac{1}{2}\right)\left| 0 \right\rangle = \tfrac{1}{2}\hbar\omega\left| 0 \right\rangle

  3. 따라서 E0=12ℏωE_0 = \tfrac{1}{2}\hbar\omega이다.

열평형 상태에서 분배함수는 Z=Tr⁡e−βHZ = \operatorname{Tr}e^{-\beta H}이다.

3 고전적 운동

고전적 해는 x(t)=Acos⁡(ωt)x(t) = A\cos(\omega t)이다. 현재 진동수는 ω=\omega =1이다.

4 한글 수식

수식 안의 한글은 그리스 문자처럼 한 음절이 한 기호다: 가1+나2=다가_1 + 나^2 = 다. 단어로 묶을 때는 에너지=12mv2\text{에너지} = \frac{1}{2} m v^2처럼 쓴다.
