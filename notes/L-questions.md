# L (5단계: Chrome 모양 뷰어) — 정한 것과 확인이 필요한 것

## 화면 배치

위에서부터 Google Chrome 과 같은 네 줄이다.

1. **탭 줄**: 둥근 탭(아이콘 · 왼쪽 정렬 제목 · ×)과 새 탭 단추(+). 선택된 탭은 아래가 바깥으로 휘어 도구줄과 이어진다.
   탭이 많으면 240px 에서 56px 까지 줄고, 그 아래로는 스크롤 단추. 불러오는 중이면 아이콘 자리에 도는 표시.
   탭 우클릭: 오른쪽에 새 탭 · 새로고침 · 복제 · 탭 닫기 · 다른 탭 닫기 · 오른쪽 탭 닫기. 가운데 클릭은 탭 닫기.
2. **도구줄**: ← → ⟳(불러오는 중이면 ×) ⌂ [주소창] ⋮.
   주소창은 알약 모양이고, 왼쪽은 페이지 정보 단추(문서 진단·호환 모드·HTTPS), 오른쪽은 확대 배율 칩(100% 가 아닐 때만)과 ☆.
3. **북마크바**: 북마크·폴더 단추. 넘치면 » 메뉴. 우클릭으로 열기·새 탭·수정·삭제·폴더 추가·숨기기. Ctrl+Shift+B.
4. **페이지**: 상태 표시줄 대신 왼쪽 아래 링크 말풍선, 찾기는 오른쪽 위에 떠 있는 상자.

메뉴는 ⋮ 에 (새 탭 · 파일 열기 · 북마크 · 확대/축소 줄 · 찾기 · 원본 보기 · 테마 · 홈 페이지 · 정보 · 종료).
macOS 는 화면 위 메뉴 막대도 둔다 (Chrome 도 그렇다). 윈도·리눅스는 메뉴 막대를 숨긴다.

## 정한 것

### 1. 창 제목 막대는 운영체제 것을 쓴다
- Chrome 은 탭을 제목 막대 안에 그린다 (창 테두리 없는 창). Qt 로도 할 수 있지만 창 끌기·크기 바꾸기·최대화 단추,
  macOS 신호등 단추, 윈도 스냅, 리눅스 Wayland 를 플랫폼마다 따로 맞춰야 하고, 이 작업 환경에서는 실제 화면으로
  확인할 수 없다. 그래서 **운영체제 제목 막대 바로 아래에 탭 줄**을 둔다. 모양과 순서는 Chrome 과 같다.
- 확인 필요: 제목 막대까지 합치기를 원하면 다음 단계에서 플랫폼별로 실제 기기에서 확인하며 한다.

### 2. 새 탭·홈 = 시작 페이지 `htexapp://start/`
- Chrome 의 새 탭 페이지처럼 로고, 주소 입력 칸, 북마크바의 북마크 바로가기 타일(최대 10), 파일 열기.
- 스크립트 없이 만들었다 (CSP `default-src 'none'`). 입력 칸·타일은 `htexapp://start/go|open|action` 으로 이동을 요청하고,
  창이 가로채 사용자가 주소창에 입력한 것처럼 연다. **시작 페이지에서 누른 것만** 받는다 (다른 문서가 같은 주소로
  링크를 걸면 무시. 테스트 `test_start_requests_from_other_pages_are_ignored`). 웹 페이지는 이 주소를 아예 불러오지 못한다(403).
- 시작 페이지만 본 탭은 "빈 탭"으로 본다 (파일 열기·단일 인스턴스가 그 탭을 다시 쓴다).
- 홈 단추가 여는 곳은 ⋮ → 홈 페이지에서 바꿀 수 있다 (`view/home`).
- 첫 창(파일 없이 실행)도 시작 페이지를 연다. 창을 코드로 만들 때(테스트)는 예전처럼 빈 탭이다.

### 3. 북마크 저장
- `bookmarks.json` (macOS `~/Library/Application Support/HyperTeX`, 윈도 `%APPDATA%\HyperTeX`, 그 밖 `$XDG_DATA_HOME/hypertex`).
  사람이 고칠 수 있는 JSON. 폴더는 한 단계. 깨진 파일은 `.broken` 으로 옮기고 빈 목록으로 시작.
- 주소는 주소창에 보이는 꼴로 저장한다 (로컬 문서는 파일 경로). `htexapp://doc-<키>` 는 실행마다 바뀌기 때문.
- 처음 실행하면 HyperTeX · 시작하기 · krunyx 세 개를 넣는다. 지우면 다시 생기지 않는다.
- ☆ / Ctrl+D 는 Chrome 처럼 바로 추가하고 이름·폴더를 고치는 상자를 띄운다 (삭제·완료).

### 4. 진단 표시 자리
- 예전 상태 표시줄의 "진단: 오류 n · 경고 n" 은 주소창 왼쪽 페이지 정보 단추로 옮겼다. 오류가 있으면 빨간 "오류 n",
  호환 모드면 "호환 모드" 글자가 붙고, 누르면 진단 목록이 뜬다. `diag_label`·`zoom_label` 이름은 F·J 테스트 때문에 그대로 둔다.

### 5. 아이콘
- Material Icons (Apache-2.0) 의 SVG 경로를 `chrome.py` 에 넣고 테마 색으로 칠한다. 따로 그림 파일이 없어 배포에 영향이 없다.
  `QtSvg` 를 쓴다 (PyInstaller 제외 목록에 없다).

## 바꾼 기존 동작
- `Tab.navigate_url` 은 웹 뷰에 초점을 먼저 준 뒤 주소를 넣는다 (setUrl 이 바로 urlChanged 를 내면 주소창 갱신이 빠졌다).
- 탭 제목을 28자에서 자르지 않는다. 막대가 폭에 맞춰 줄여 그린다.
- 문서를 열 때 상태 표시줄에 띄우던 "해석 n ms" 는 페이지 정보 상자로 옮겼다.
