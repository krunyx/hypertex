# R 파일 열기 (v0.8.0) — 결정과 확인 필요 항목

## 1. 결정

- **파일 단추 자리**: 도구줄의 홈(⌂) 단추와 주소창 사이. 새 동작을 만들지 않고 기존 `act_open`(파일 열기, Ctrl+O)을
  그대로 단다. 아이콘은 열린 폴더 모양(`folder_open`, Material 아이콘과 같은 꼴)으로 새로 넣었다.
- **놓기 영역은 창 전체**: 주소창(`AddressEdit.files_dropped`), 창(`ViewerWindow.dropEvent`), 페이지 모두.
  웹 엔진의 안쪽 렌더 위젯은 놓기를 스스로 받으므로 `FileDropFilter` 로 **로컬 파일 놓기만** 가로채 창이 연다.
  렌더 위젯이 다시 만들어질 때(렌더 프로세스 재시작)를 위해 `ChildAdded` 때 필터를 다시 단다.
- **글자·웹 주소 끌기는 건드리지 않는다**: `dropped_paths` 는 로컬 파일만 고르고(폴더 제외), 없으면 원래 처리로 넘긴다.
- **여러 파일**: 첫 파일은 지금 탭(편집 중인 탭이면 `navigate` 규칙대로 새 탭), 나머지는 뒤쪽 새 탭.
  Chrome 은 페이지에 놓으면 지금 탭, 탭 줄 사이에 놓으면 그 자리 새 탭인데, 자리 계산은 하지 않았다.
- **확장자 검사는 하지 않는다**: 열 수 없는 파일은 주소창에 경로를 친 것과 같이 `ViewerCore.input_to_url` 의 진단을 따른다.

## 2. 확인 필요

- 원문 편집기(왼쪽 칸)에 파일을 놓으면 지금은 편집기 쪽 웹 엔진이 받는다. 편집기에도 같은 필터를 달지 정할 것.
- 탭 줄 두 탭 사이에 놓으면 그 자리에 새 탭을 여는 Chrome 동작은 다음 버전 후보.

## 3. 북마크 가져오기 (v0.8.1) — 결정

- **중첩 폴더**: 북마크 폴더 안에 폴더를 둔다 (전에는 한 단계만). 깊이는 `MAX_DEPTH`(8) 에서 자르고, 가져올 때
  더 깊은 폴더의 북마크는 버리지 않고 위 폴더로 올린다. 북마크바 폴더 메뉴는 하위 폴더를 하위 메뉴로 보이고,
  하위 메뉴는 처음 열 때 채운다 (북마크가 수천 개여도 빨리 뜨게). ☆ 상자의 폴더 목록은 "A › B" 경로로 보인다.
  `tests/unit/test_L_bookmarks.py` 의 "중첩 폴더를 버린다" 검사를 "중첩 폴더를 둔다"로 바꿨다.
- **두 길**: (1) Chromium 계열 프로필의 `Bookmarks` JSON 을 직접 읽는다 (Chrome, Edge, Brave, Whale, Vivaldi,
  Chromium; 프로필 이름은 `Local State`). 브라우저가 열려 있어도 읽기만 하므로 괜찮다.
  (2) 모든 브라우저가 내보내는 Netscape HTML 북마크 파일. 북마크바는 `PERSONAL_TOOLBAR_FOLDER="true"` 표시,
  표시가 없으면(Safari) 이름이 Favorites·Bookmarks bar 인 폴더, 그것도 없으면 맨 위 항목 전체.
- **어디에 넣나 (Chrome 의 가져오기와 같다)**: 북마크바가 비었거나 처음 넣어 둔 기본 북마크뿐이면 가져온
  북마크바 항목을 그대로 북마크바 끝에, 아니면 "<브라우저>에서 가져옴" 폴더 하나에. 북마크바 밖의 것(기타·모바일
  북마크)은 "기타 북마크" 폴더로.
- **겹치지 않게**: 이미 있는 주소(끝의 / 차이 무시)는 건너뛴다. 다시 가져와도 늘지 않는다.
- **건너뛰는 주소**: `javascript:` 북마크릿, `chrome://`·`edge://`·`about:` 같은 브라우저 내부 주소, `data:`.
  `file://` 는 주소창에 넣는 로컬 경로로 바꾼다.
- 가져온 뒤 북마크바가 숨겨져 있으면 보이게 한다.

## 4. 확인 필요 (북마크)

- 한국어 Safari 가 표시 없이 "즐겨찾기" 이름으로 내보내는 경우는 이름으로 찾지 않는다 (화면 글자 검사
  `test_P_i18n` 이 코드 안의 한국어 문자열을 막아서). 그때는 모든 항목이 북마크바로 들어간다. 필요하면
  `test_P_i18n` 의 허용 목록에 넣고 `_BAR_NAMES` 에 더할 것.
- Firefox 의 `places.sqlite` 직접 읽기는 하지 않았다 (HTML 내보내기로 충분하다고 봄).
- 북마크 관리자(폴더 안에 새 폴더 만들기, 끌어서 옮기기)는 아직 없다. 하위 폴더는 가져오기로만 생긴다.

## 5. 세션 복원·닫은 탭 다시 열기 (v0.8.1) — 결정

- **기본은 "이전 탭 다시 열기"** (Chrome 의 기본은 새 탭 페이지지만, 로드맵에서 "재실행 시 탭 유지"로 정했다).
  ⋮ › 시작할 때 에서 "새 탭 페이지 열기"로 바꿀 수 있다 (`QSettings` 의 `startup/mode`).
- **저장**: 사용자 데이터 폴더의 `session.json` (`htex/viewer/session.py`). 탭이 바뀌면(주소·제목·순서·지금 탭·
  닫기) 0.8초 뒤에 저장하고, 창을 닫을 때 한 번 더. 그래서 강제 종료돼도 거의 마지막 상태가 남는다.
  주소는 북마크와 같은 꼴(로컬 문서는 파일 경로). 원문 보기·빈 탭·멈춘 탭은 저장하지 않는다.
- **켤 때**: 이전 탭을 같은 차례로 열고 그때의 지금 탭을 고른다. 파일을 열며 켰으면(더블클릭·`htex view a.htex`)
  이전 탭 뒤에 그 파일 (Chrome 과 같다). 새 탭 페이지 하나뿐인 세션은 없는 것으로 친다.
- **세션을 쓰는 창은 `run()` 이 만든 창뿐**: 테스트·다른 코드가 `ViewerWindow` 를 직접 만들면 저장하지 않는다
  (`session_path is None`). `HTEX_VIEWER_SESSION=0` 이면 `run()` 도 쓰지 않는다.
- **닫은 탭 다시 열기** (Ctrl+Shift+T, 탭 우클릭 메뉴, macOS 파일 메뉴): 최근 25개를 기억하고 원래 자리에 연다.
  창을 닫은 뒤(마지막 탭 닫기)의 탭은 기억하지 않는다 — 다음에 켤 때 세션으로 돌아온다.

## 6. 확인 필요 (세션)

- 창이 여러 개면 마지막에 저장한 창의 탭만 남는다 (지금 뷰어는 단일 인스턴스·창 하나가 보통).
- 탭마다의 뒤로·앞으로 기록과 스크롤 위치는 저장하지 않는다.
- 이전 탭을 모두 한꺼번에 불러온다. Chrome 처럼 고른 탭만 먼저 불러오는 지연 로딩은 탭이 많아지면 검토.
