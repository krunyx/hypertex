# R 파일 열기 (v0.8.0) — 결정과 확인 필요 항목

## 1. 결정

- **파일 단추 자리**: 도구줄의 홈(⌂) 단추와 주소창 사이. 새 동작을 만들지 않고 기존 `act_open`(파일 열기, Ctrl+O)을
  그대로 단다. 아이콘은 열린 폴더 모양(`folder_open`, Material 아이콘과 같은 꼴)으로 새로 넣었다.
- **놓기 영역은 창 전체**: 주소창(`AddressEdit.files_dropped`), 창(`ViewerWindow.dropEvent`), 페이지 모두.
  웹 엔진의 안쪽 렌더 위젯은 놓기를 스스로 받으므로 `FileDropFilter` 로 **로컬 파일 놓기만** 가로채 창이 연다.
  렌더 위젯이 다시 만들어질 때(렌더 프로세스 재시작)를 위해 `ChildAdded` 때 필터를 다시 단다.
- **글자·웹 주소 끌기는 건드리지 않는다**: `dropped_paths` 는 로컬 파일만 고르고(폴더 제외), 없으면 원래 처리로 넘긴다.
- **여러 파일**: 첫 파일은 지금 탭(편집 중인 탭이면 `navigate` 규칙대로 새 탭), 나머지는 뒤쪽 새 탭.
  Chrome 은 페이지에 놓으면 지금 탭, 탭 줄 사이에 놓으면 그 자리 새 탭인데, 자리 계산은 하지 않았다.
- **확장자 검사는 하지 않는다**: 열 수 없는 파일은 주소창에 경로를 친 것과 같이 `ViewerCore.input_to_url` 의 진단을 따른다.

## 2. 확인 필요

- 원문 편집기(왼쪽 칸)에 파일을 놓으면 지금은 편집기 쪽 웹 엔진이 받는다. 편집기에도 같은 필터를 달지 정할 것.
- 탭 줄 두 탭 사이에 놓으면 그 자리에 새 탭을 여는 Chrome 동작은 다음 버전 후보.
