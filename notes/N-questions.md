# N 단계: macOS 제목 막대 탭 — 결정과 확인 필요

## 한 일
macOS 에서 탭 줄을 운영체제 제목 막대 자리로 올렸다 (Chrome 과 같은 모양). 윈도·리눅스는 L 단계 그대로
(운영체제 제목 막대 아래 탭 줄).

- Qt 6.9+ 의 `ExpandedClientAreaHint`(내용을 제목 막대 밑까지)와 `NoTitleBarBackgroundHint`(막대 배경 없음).
  창의 `WA_ContentsMarginsRespectsSafeArea` 는 끈다 (켜 두면 Qt 가 내용을 막대 높이만큼 다시 내린다).
- 신호등 단추(닫기·최소화·확대), 창 크기 바꾸기, 전체 화면은 macOS 가 그대로 한다.
- 탭 줄 왼쪽 78px 은 신호등 자리로 비운다. 전체 화면에서는 단추가 숨으므로 비우지 않는다.
- 탭 줄의 빈 곳(탭 사이·＋ 오른쪽)을 누르면 `QWindow.startSystemMove()` 로 창 끌기.
- 빈 곳 더블클릭은 시스템 설정(데스크탑 및 Dock › 윈도우 제목 막대 이중 클릭)을 따른다: 확대 · 최소화 · 아무것도 안 함.
  L 단계에서는 새 탭이었다 (윈도 Chrome 동작). macOS Chrome 은 확대이므로 맞췄다.
- 제목 글자는 숨긴다 (NSWindow.titleVisibility). 제목 자체는 두므로 Dock·미션 컨트롤·윈도 메뉴에는 나온다.
  Qt 에 없는 이 두 가지(제목 숨기기, 더블클릭 설정 읽기)만 Objective-C 런타임을 ctypes 로 부른다 (`htex/viewer/macwin.py`, 의존성 추가 없음).
- 끄기: macOS 메뉴 막대 › 보기 › "탭을 제목 막대에 표시" (다시 시작하면 적용). 설정 키 `view/titlebar_tabs`.
- 실제 Cocoa 창이 아니면(offscreen 테스트, Qt 6.9 미만) 아무것도 하지 않는다.

## 확인 필요 (실제 맥에서)
- 신호등 단추와 탭의 세로 위치: 단추는 macOS 가 막대(약 28px) 가운데에 두고, 탭 줄은 40px 이다.
  어긋나 보이면 단추를 옮기거나(네이티브) 탭 줄 높이를 맞춘다.
- 다크 모드·창 비활성 때 탭 줄 색. Chrome 은 비활성 창의 탭 줄을 흐리게 한다 (아직 안 함).
- 탭 끌기(순서 바꾸기)와 창 끌기가 섞이지 않는지.

## 남은 것
- 윈도: 테두리 없는 창 + 직접 그린 최소화·최대화·닫기, WM_NCHITTEST 로 스냅 레이아웃·가장자리 크기 조절.
- 리눅스: 선택 사항으로만 (데스크톱 환경마다 다르다).
