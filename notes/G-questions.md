# G (웹 폴백) 질문과 임시 가정

## 1. 조각 주소의 doc 값 형식 (docs/interaction-protocol.md 4절)
- 문제: "doc=<다른 문서 주소>"가 링크의 href 그대로(상대 주소 `11-internal-refs.htex`)인지, 해석된 절대 주소인지 정해져 있지 않다.
  상대 주소는 기준 문서를 모르면 해석할 수 없다.
- 제안: "스크립트가 document.baseURI 기준으로 해석한 주소. 같은 출처면 경로(/a/b.htex), 아니면 절대 URL"로 명시.
- 임시 가정: interact.js 는 그렇게 보낸다. 웹 서버는 `/`로 시작하는 경로 또는 Host 헤더와 같은 출처의 http(s) 절대 주소만 받고,
  상대 주소·외부 주소·htex:// 는 404 (서버는 외부 문서를 대신 가져오지 않는다: SSRF 방지). 뷰어(F)는 htex:// 를 받을 수 있다.
  다른 출처 문서는 스크립트가 아예 요청하지 않는다(웹 서버의 조각 주소가 http(s)일 때).

## 2. 조각의 범위 (4절 "그 라벨 블록 하나")
- 문제: 라벨이 식 행, 절, 목록 항목, 단계에 붙을 때 "블록 하나"가 무엇인지 불명확. 절 전체는 미리보기로 너무 길다.
- 임시 가정(htex/web/fragment.py, interact.js 같은 문서 복제도 같은 규칙):
  식 행 → 그 행만 담은 같은 환경, 절 → 제목 + 처음 두 블록 + "…", 목록 항목·단계 → 그 항목만 담은 목록(번호 유지),
  그 밖 → 블록 전체. 조각 맨 앞에 `<div class="htex-fragment-head">문서 제목 · 식 (1)</div>`.
  조각 안 `#라벨` 링크와 상대 주소는 조각 문서 기준(/a/b.htex#라벨)으로 바꾼다.
- 제안: 규약 4절에 이 규칙(또는 다른 규칙)을 적어 F와 G가 같은 모양을 보이게.

## 3. 그림 주소 실패 상태 코드 (3절)
- 문제: "실패하면 4xx"만 있다.
- 임시 가정: 문서·노드가 없으면 404, 노드는 있는데 렌더러가 None이면 422, 쿼리 형식 오류(숫자 아님·NaN·Inf·node 없음) 400.
  선언되지 않은 매개변수 이름은 조용히 버린다. 범위 밖 값은 render_picture_node가 자른다(H 계약).

## 4. 캐시와 의존 파일
- 문제: 문서 캐시는 (수정 시각, 크기)로만 판단해 `\usemacros`·`\usestyle`·`\input`·`\transclude`가 읽은 다른 파일이 바뀐 것을 모른다.
- 제안: 파서(C)가 트리에 읽은 로컬 파일 목록(`source.dependencies`)을 남기면 서버가 함께 확인할 수 있다.
- 임시 가정: 의존 파일 변경은 무시. 고친 문서를 저장(touch)하면 갱신된다.

## 5. 정적 빌드의 다른 문서 미리보기와 그림
- 규약대로 정적 사이트에는 그림·조각 meta 를 넣지 않는다: 슬라이더는 숫자만 바뀌고 그림은 기본값, 다른 문서 미리보기 없음
  (같은 문서 미리보기는 동작). H가 완성되면 빌드 때 기본값 SVG를 렌더러(b_picture)가 넣을 것으로 가정.
- 제안(선택): 빌드 때 라벨마다 조각 파일(`_htex/fragments/문서/라벨.html`)을 미리 만들고 meta 로 "정적 조각 주소 틀"을 알리는 방식을 규약에 추가.

## 6. 정적 사이트의 .htex 링크 변환 범위
- 임시 가정: 상대 주소이고 경로가 .htex/.tex 로 끝나는 링크만 .html 로 바꾼다. htex:// → https:// (웹 폴백) 링크는 다른 서버의 문서라
  확장자를 그대로 둔다(그 서버가 HTML을 주는지 모름). 같은 폴더에 a.htex 와 a.tex 가 함께 있으면 a.htex → a.html, a.tex → a.tex.html.

## 7. CSP 의 style-src 'unsafe-inline'
- 문제: 렌더러가 CSS를 `<style>`로 인라인하고 이미지 폭을 style 속성으로 준다(E 계약: "CSS 인라인 단일 파일"). 스크립트만 막고 스타일은 인라인을 허용해야 한다.
- 임시 가정: `script-src 'self'`(인라인 스크립트 불가), `style-src 'self' 'unsafe-inline'`, `img-src 'self' https:`.
  정적 빌드는 `<meta http-equiv>`로 같은 정책(frame-ancestors 는 meta 로 줄 수 없어 뺌).

## 8. 매개변수 값 표시 형식
- 문제: 슬라이더를 움직일 때 표시 자릿수가 정해져 있지 않다(렌더러 format_number 는 파이썬 repr 기준).
- 임시 가정: step(없으면 범위/100을 1·2·5×10^k로 반올림)·min·기본값의 소수 자릿수 중 가장 큰 것으로 자르고 끝의 0을 뺀다(1.0→"1").
  step 이 없을 때 슬라이더 간격도 같은 값. 이것이 명세 3.2절 `[step=…]` 생략 시 기본값과 같아야 하는지는 미정.
